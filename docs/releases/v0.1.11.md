# OneTint 0.1.11

Color controls for Samsung Keyboard, Quick Panel, notifications and volume. Root required.

- Pick one accent color, with separate notification background, text and icon colors.
- Choose black or white Quick Panel and volume icons.
- AMOLED keyboard background with a translucent gray key pop-up (`#80171717`).

The latest build removes the extra notification preview and fixes the pop-up's opacity.

Restore previous colors before uninstalling or clearing app data. The latest changes still need phone testing, so this is a pre-release.
